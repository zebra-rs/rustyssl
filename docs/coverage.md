# Export coverage

Generated by `cargo xtask coverage` from the OpenSSL 3.5 export lists. Don't edit it by hand:
CI fails if it's out of date.

An export is **implemented** once `rustssl-capi` defines it and a C conformance test in `tests/c/`
calls it. Every other export is a generated stub that aborts (AGENTS.md, security rule 10).
