# The data files of upstream OpenSSL's `evp_test` (test/recipes/30-test_evp_data/) that
# `cargo xtask test-openssl-suite` runs with the reference's `evp_test` program on the reference
# libraries and on rustyssl's. Both runs must succeed with the same "Completed N tests with E
# errors and S skipped" lines, and the same number of ERROR lines (evp_test counts a key
# generation it can't start as passed). A file is added once its algorithms and the functions
# the program uses on them are implemented: the key-pair files need key parsing
# (PEM_read_bio_*) and the key-generation files their key types (Phase 4), for instance.
# evpciph_aes_stitched.txt's AES-CBC-HMAC composites are offered on x86_64 with AES-NI only
# (elsewhere both libraries skip them). The runs load the default and legacy providers (test/default-and-legacy.cnf), as the recipe does
# when the legacy module is built; each library finds its own module through OPENSSL_MODULES.
