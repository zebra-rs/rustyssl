# The data files of upstream OpenSSL's `evp_test` (test/recipes/30-test_evp_data/) that
# `cargo xtask test-openssl-suite` runs with the reference's `evp_test` program on the reference
# libraries and on rustyssl's. Both runs must succeed with the same "Completed N tests with E
# errors and S skipped" lines. A file is added once its algorithms and the functions the
# program uses on them are implemented: the key-pair files need key parsing (PEM_read_bio_*),
# for instance; evpciph_aes_stitched.txt (the AES-CBC-HMAC composites, offered on x86_64 with
# AES-NI) needs TLS record mode (`tls-version`), which arrives with libssl in Phase 7. The
# legacy provider isn't loaded (test/default.cnf), so its tests are skipped.
