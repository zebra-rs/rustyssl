# tlsfuzzer scripts for `cargo xtask test-tlsfuzzer` (TEST_PLAN.md, layer L7).
#
# Each script runs against the reference's `openssl s_server`, once on the reference's
# libraries and once on rustyssl's; the harness adds `-h 127.0.0.1 -p <port>`. A conversation
# that fails on rustyssl but not on the reference is a failure; one both fail is reported
# but not counted.
#
# Lines:
#   pin <name> <owner/repository> <commit> <sha256 of the GitHub tarball>
#   server <s_server arguments>     the server for the script lines that follow
#   script <file> [arguments]       a script run by default
#   timing <file> [arguments]       a timing script, run only with --timing
# Arguments are split at spaces; "double quotes" keep one with spaces. `{tf}` is the
# tlsfuzzer tree (its tests/ directory holds the keys and certificates).
