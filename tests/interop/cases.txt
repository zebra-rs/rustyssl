# TLS interop cases (cargo xtask test-interop): name | s_server arguments | s_client arguments.
# Placeholders: {rsa} {ec} {p521} {ed25519} {mldsa65} (the server's certificate and key), {client} (the
# client's), {ca} (the root), {srpvfile} (an SRP verifier file: user "user", password
# "password"), {dir} (the PKI's directory).
# Client directives: +full (no -brief; the session lines), +resume (a second connection
# resuming the first's session), +early (with +resume: early data on the second), +cmd=X (send the command line X, R or k or K, first).
# +faults (DTLS): the client talks through a relay that drops, duplicates and reorders
# handshake datagrams by a schedule from --seed and the case.
# A DTLS case (a server argument -dtls*) runs over UDP without -rev: no echo, the summaries and
# the server's output (including the line the client sent) are compared.
# Each case runs in four pairings (reference/reference is the expectation; the server echoes
# lines reversed and closes on CLOSE).
