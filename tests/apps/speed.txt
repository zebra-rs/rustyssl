# Async jobs: rustyssl's ASYNC_is_capable() is 0 (docs/DEVIATIONS.md), where speed says so
# and, in test mode, succeeds; so these must only succeed (on the reference, the jobs run).
~speed -testmode -async_jobs 1 sha256 rsa1024
~speed -testmode -async_jobs 4 -evp aes-128-gcm -aead ecdsap256 ed25519 ffdh2048
~speed -testmode -async_jobs 2 -mr -bytes 64 sha1 hmac
# -mb with -async_jobs: upstream refuses it after checking the cipher ("Async mode is not supported
# with -mb", reached only where a multi-block cipher exists: x86_64's stitched AES-CBC-HMAC);
# rustyssl's ASYNC_is_capable() is 0 (docs/DEVIATIONS.md), so there both tools stop earlier, at
# "async not supported". Only the failure is compared; on the reference library ours prints
# upstream's text byte for byte (checked on macOS, where both stop at the unknown cipher).
~speed -mb -async_jobs 2 -evp AES-128-CBC-HMAC-SHA1
~speed -mb -async_jobs 1 -evp aes-128-cbc
